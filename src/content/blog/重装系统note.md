# 一、两种重装系统方式

## 1. 下载 Windows 镜像，基于现有系统直接安装（不推荐）

优点：方便快捷。

缺点：重装系统不彻底，可能会残留现有系统文件。

## 2. 下载 Windows 镜像至 U 盘，让 U 盘作为启动盘进行安装

优点：重装彻底，格式化盘符更加彻底，能解决大部分现有系统问题。

缺点：技术要求更高。

推荐使用微 PE 工具箱辅助重装系统，更加方便，而且能在 U 盘里面装多个操作系统镜像 ISO 文件，重装系统版本更随意。若不用微 PE 工具箱，传统方式直接制作启动盘时，U 盘会被格式化，且通常只能装载一个 ISO 文件。

# 二、重装系统具体步骤

1. 插入带有微 PE 工具箱和目标系统 ISO 文件的 U 盘。
2. 重启电脑，在出现电脑厂商 Logo 的瞬间快速按快捷键进入 BIOS。不同品牌按键不同，机械革命是 `F2`，台式电脑一般是 `Delete`。
3. 在 Boot 启动项里把第一启动项改为 U 盘，进入 PE 操作系统。PE 可以理解为简易版 Windows，让系统能在 U 盘上运行。
4. 在 PE 系统里使用重装工具，格式化系统盘并安装系统。
5. 注意分区格式：
   - UEFI 启动 + GUID 分区表（GPT）：适合 Windows 10/11、Linux。
   - Legacy 启动 + MBR 分区：适合较旧设备或旧系统。
6. 安装完成后拔出 U 盘。一般系统会自动变更为电脑硬盘启动。
7. 进入系统后，去电脑厂商官网安装对应电脑型号的驱动。
